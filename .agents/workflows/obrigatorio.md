---
description: Sempre que receber uma solicitação para criar ou alterar uma página:
---

ETAPA 1 — ANALISAR

Antes de escrever código:

verificar a estrutura atual do projeto;
identificar componentes existentes;
identificar estilos existentes;
verificar se já existe um componente que pode ser reutilizado.
ETAPA 2 — PLANEJAR

Apresentar brevemente:

estrutura da página;
componentes que serão utilizados;
novos componentes necessários;
arquivos que serão criados ou alterados.

Não gerar código ainda nesta etapa.

ETAPA 3 — IMPLEMENTAR

Depois da análise:

criar a estrutura React;
criar os componentes necessários;
utilizar dados mockados quando necessário;
manter separação entre dados e apresentação;
reutilizar componentes globais.
ETAPA 4 — RESPONSIVIDADE

Verificar:

desktop;
tablet;
mobile;
menu;
imagens;
cards;
grids;
textos;
botões.

Nenhum elemento deve causar overflow horizontal.

ETAPA 5 — REVISÃO

Verificar:

console sem erros;
imports corretos;
caminhos das imagens;
componentes funcionando;
navegação funcionando;
estilos consistentes;
acessibilidade básica;
HTML semântico.
ETAPA 6 — EXPLICAR

Depois da implementação, explicar:

O que foi criado.
Quais arquivos foram alterados.
Por que cada componente foi criado.
Como a página se conecta ao restante do projeto.
O que ainda será necessário implementar futuramente.
REGRA DE APRENDIZADO

Não esconder decisões importantes.

Quando uma estrutura nova for utilizada, explicar brevemente o motivo.

Se houver uma maneira significativamente melhor de estruturar o código, apresentar a alternativa antes de implementá-la.

O objetivo não é apenas construir o site, mas também me ajudar a aprender React enquanto construímos o projeto.
