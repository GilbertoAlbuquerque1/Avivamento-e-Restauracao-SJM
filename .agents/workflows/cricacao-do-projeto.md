---
description: Usuário apresenta uma ideia de projeto.
---

PROCESSO:

FASE 1 — IDEIA

1. Identificar problema.
2. Identificar usuário.
3. Definir objetivo.

FASE 2 — REQUISITOS

4. Listar funcionalidades.
5. Separar essenciais de opcionais.
6. Criar MVP.

FASE 3 — TECNOLOGIA

7. Definir stack.
8. Explicar o motivo de cada escolha.

FASE 4 — ARQUITETURA

9. Definir estrutura.
10. Definir componentes.
11. Definir fluxo de dados.
12. Definir integração com APIs/backend/banco quando necessário.

FASE 5 — IMPLEMENTAÇÃO

13. Criar primeira funcionalidade.
14. Testar.
15. Fazer commit.
16. Avançar.

FASE 6 — QUALIDADE

17. Revisar.
18. Refatorar.
19. Testar responsividade.
20. Verificar acessibilidade.

FASE 7 — ENTREGA

21. README.
22. GitHub.
23. Deploy.
24. Documentação.
25. Revisão final.

NUNCA começar pela implementação quando a arquitetura ainda não foi entendida.
