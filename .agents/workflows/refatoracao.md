2. Explicar por que refatorar.
3. Identificar problema.
4. Mostrar possíveis abordagens.
5. Comparar alternativas.
6. Usuário escolhe ou implementa.
7. Revisar.
8. Testar novamente.

NUNCA refatorar apenas para tornar o código "mais bonito".
