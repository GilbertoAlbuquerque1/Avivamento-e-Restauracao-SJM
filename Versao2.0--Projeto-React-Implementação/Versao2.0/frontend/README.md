# Avivamento & Restauração SJM

Site institucional da Igreja Avivamento & Restauração SJM, desenvolvido com React e Vite.

O projeto tem como objetivo oferecer uma presença digital moderna, responsiva e acessível para a igreja, disponibilizando informações institucionais, eventos, formas de contato e recursos de apoio aos visitantes e membros.

A aplicação também está sendo estruturada pensando em uma futura evolução para uma plataforma digital com funcionalidades destinadas a membros, líderes e administradores.

---

## Sobre o Projeto

O Avivamento & Restauração SJM é um projeto web institucional desenvolvido para uma igreja local em São João da Madeira, Portugal.

A aplicação foi construída utilizando React, com uma arquitetura baseada em componentes reutilizáveis e separação de responsabilidades.

O projeto representa uma aplicação real de desenvolvimento frontend e está sendo desenvolvido de forma incremental, permitindo a implementação de novas funcionalidades conforme a arquitetura evolui.

---

## Objetivos

O projeto possui dois objetivos principais.

### Objetivo institucional

Disponibilizar uma plataforma digital para:

* Apresentar a igreja;
* Informar horários e atividades;
* Divulgar eventos;
* Facilitar o contato com a igreja;
* Disponibilizar informações de apoio;
* Apresentar os ministérios e atividades;
* Facilitar a comunicação com visitantes e membros.

### Objetivo técnico

Aplicar conhecimentos de desenvolvimento web moderno, incluindo:

* React;
* JavaScript;
* Componentização;
* Props;
* Estado;
* Eventos;
* Renderização condicional;
* Formulários;
* Organização de projetos;
* CSS responsivo;
* Git e GitHub;
* Arquitetura frontend.

## Funcionalidades atuais

### Página inicial

A página inicial apresenta as principais informações da igreja e direciona o visitante para as áreas mais importantes do site.

### Navegação

O projeto possui navegação entre as principais áreas da aplicação, com estrutura responsiva para dispositivos móveis.

### Sobre Nós

Área destinada à apresentação da igreja, sua identidade e informações institucionais.

### Eventos

Área destinada à divulgação de eventos e atividades da igreja.

Entre os conteúdos previstos estão:

* Encontro com Deus;
* Células;
* Programações;
* Inscrições.

### Área de Ajuda

A aplicação possui uma área destinada a pessoas que procuram apoio.

Categorias previstas:

* Apoio espiritual;
* Apoio social;
* Outros pedidos de ajuda.

### Layout responsivo

A interface foi desenvolvida considerando diferentes tamanhos de tela, incluindo:

* Desktop;
* Tablet;
* Smartphone.
